  and a multi-tenant Terraform foundation on AKS.
- **Backend at scale** — Java, Spring Boot and Spring WebFlux services for over-the-air updates and
  vehicle management in automotive, plus the service routing and request-validation layer behind them.
- **Cloud infrastructure** — Azure and AWS, Terraform, Helm, ArgoCD, GitHub Actions and GitLab CI.
- **AI agent systems** — co-designed an agent orchestration platform and owned the architecture of two
  subagents; built an AI-powered RDP agent that drives automated end-to-end UI testing on Windows.
  Currently migrating the orchestration platform from Java/LangGraph4j to Python with LangGraph and FastAPI.
